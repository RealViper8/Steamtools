# Contributing to Steamtools
Thank you for your interest to contribute to Steamtools

## How to Contribute

### Reporting Bugs, Issues
* Before creating an issue make sure to check [Issues](https://github.com/RealViper8/Steamtools/issues) to avoid any duplicates.
* When reporting a bug make sure to specify:
  * Your os
  * Steps to reproduce
  * Logs (if possible) / Stack traces

### Code Contributions
If you want to add a new feature or fix an existing issue make sure to:
**Fork** the repository and make the commit messages clear and concise.
Then push to your fork and open a PR.
