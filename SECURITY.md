# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
|   0.4.1 | :white_check_mark: |
|   0.3.1 | :white_check_mark: |
| > 0.2.1 | :white_check_mark: |
| < 0.2.1 | :x:                |

## Reporting a Vulnerability

If you want to report a vulnerability go to [issues]("https://github.com/RealViper8/Steamtools/issues").
